# Windows-Command-Center
Programa para visualizar los comandos de CMD enlistados.
Cada comando puede ser ejecutado desde el programa o copiando el comando y ejecutandolo desde CMD

########## Como Instalar ##########

1) Descargar la ultima version del programa.
2) Extraer "Windows_Command_Center_V1.0.exe" del archivo ZIP.
3) Ejecutar programa.



⚠⚠⚠ ADVERTENCIA ⚠⚠⚠
NO TODOS LOS COMANDOS HAN SIDO PROBADOS ADECUADAMENTE Y PUEDEN NO FUNCIONAR
